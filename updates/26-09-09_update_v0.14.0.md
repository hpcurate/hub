# v0.14.0 — direct card editing and upload dismissal

- Latest-video previews can be dismissed per upload, with seven exit choices.
- New-upload cues settle on hover and retain a small indicator; the text label is optional.
- Manual mode exposes every card element and supports drag-to-zone placement.
- Card facts and category icons are independent movable elements.
- Home-page resize controls cover width, height, card corners, and background scale.
- Heading, body, and metadata fonts can be selected separately.
- Card exit, reorder, filter, and panel animations have their own controls.
- Enrichment repaints only the channel that changed, clock updates run once per minute, and entry classes are removed after their first play.

Validation: `npm test` in `test/` (487 board checks plus scope, Instagram, YouTube, guard, bridge, and popup suites).
