# v0.15.0 — ordered manual layouts

- Cards smoothly return to their normal height when a latest-upload preview is dismissed.
- Cards no longer stretch to match a taller card elsewhere in their grid row.
- Manual mode can insert a dragged element before or after another element in the same zone.
- Element order is saved with the layout and survives exports, presets, reloads, and older stored boards.
- The backup harness now runs on Windows PowerShell 5.1 and excludes generated dependencies and browser artifacts.
