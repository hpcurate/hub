## What was done

The repo was empty, so this is the whole app: `index.html`, two stylesheets, two
scripts, a jsdom harness and a README. No build step, no dependencies at
runtime — open the file.

### The look — tasks 1 and 2

`css/tokens.css` is ROOT's token layer, copied rather than re-invented: the same
VOID palette, the same `--r-base` shape anchors, the same `--dur-*` motion
scale, under the same names. "Same design language" is easiest to keep true over
time if the variables are literally the same variables. What is *not* carried
over is ROOT's appearance engine — no themes, no dials, no `prefs.js`. HUB is one
board in one look, which is what "very simple" asked for.

Type is the pair the task named. "Grotesk" is ROOT's own label for its Space
Grotesk pairing (`root/js/prefs.js`), so titles are Space Grotesk 600/700 and
everything else is JetBrains Mono. The title band is ROOT's: a small uppercase
label line, then the wordmark with its one-pixel accent shadow, `HUB.` with the
dot inheriting from the word rather than being coloured separately.

### The board — task 1

`grid-template-columns: repeat(auto-fill, minmax(min(var(--min),100%), 1fr))` is
the whole of "items that scale to window size": the column count follows the
window and the columns share the remainder, so there is no horizontal scrollbar
at any width and no ragged right edge. The S/M/L control moves `--min`, not the
count.

Each card is the link. An absolutely-positioned anchor fills the tile with the
text above it and pointer-events off, so a click anywhere opens the channel and
the browser still shows the real URL on hover. The edit button is the one thing
that takes pointer events back.

### Categories and colour — tasks 1 and 2

Five defaults are seeded on a cold start (learning, making, tech, music, watch)
and every one of them is renamable, recolourable and deletable like any category
made later — they are a starting point, not a schema. New ones can be made in
the category sheet, or inline while filing a channel.

Colour is a ten-hue palette held at roughly one lightness, so no category shouts
louder than another on a dark ground. A category's colour is its spine down the
left of every card, its dot on the filter chip, and a faint wash across the tile.

**Decision made on Hugo's behalf:** deleting a category does not delete its
channels. They fall back to uncategorised, which the board shows in muted grey
and the filter can still reach. Losing channels because a category went is not a
trade worth offering.

### Sort, filter, search — task 2

One `list()` builds the board: filter by the selected category chips, then the
search term over name + description + category name, then sort. Five orders:
last viewed, longest unwatched, recently added, name, category.

**Decision made on Hugo's behalf:** the request asked for last-viewed as "a
sorting option", singular, but the useful question is usually the other one —
what has gone longest without a watch. Both are there rather than a guess at
which one was meant.

### Time since last viewed — task 2

The stamp is written on the same click that opens the tab, so "last viewed"
means "last time I actually went there". The card shows it coarsely — just now,
4h ago, 3d ago, 2w ago, never — because "23 days" is the same answer as "3 weeks"
with a decimal point. A 30-second timer repaints only that one label, so a board
left open all day stays honest without anything reordering under the cursor.

### Animations — task 2

Reordering is a FLIP: measure every card, do the reorder, measure again, play
each card from where it was back to where it now is. A grid moves items by
changing their boxes, which no CSS transition can follow, so the sort, the
filter and the size control all animate through the same path. New cards rise in
on a per-index stagger, removed cards fade out before they go, sheets scale up
off a scrim, and everything multiplies by `--mo`, which
`prefers-reduced-motion` sets to 0 in one declaration.

### Two defects the harness found

- **Alphabetical sort was not alphabetical.** Most YouTube names are `@handles`,
  and `localeCompare` treats punctuation as non-ignorable, so every handle
  clumped above every plain name and the order called itself A–Z. The `@` is
  part of the URL scheme, not the first letter of a name, so it is dropped for
  the comparison.
- **Closing a sheet left focus in a hidden field**, and every keyboard shortcut
  stands down while you are typing — so `/` and `n` were dead until something
  else was clicked. `closeSheet()` now blurs.

Also fixed before it shipped: the URL box was `type="url"`, which refuses
anything without a scheme, while a URL copied off a page is very often pasted
bare. It is a text input now and the store adds the `https://`.
