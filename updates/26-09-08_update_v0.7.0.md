## What was done

### The flying cards — bug 1

The FLIP measured every card against the **viewport**. Filtering the board makes
it shorter; a shorter page makes the browser clamp the scroll position; and a
rect taken before that clamp is in a different frame from one taken after. Every
remaining card then looked like it had moved by the whole scroll delta, and
dutifully animated in from where it would have been if the page had not
scrolled — which from a board scrolled down is the top of the screen.

Positions are now measured against the **document**: the scroll offset is added
at measure time and subtracted at apply time, so a scroll that happens in
between cancels out. There is also a cap — past 1600px a card simply appears
where it now is, because a card that has genuinely moved most of a page is not
worth watching travel.

### The strip that would not go — bug 2

`[hidden]{display:none}` is a **user-agent** rule, and a user-agent rule loses to
any class in our own stylesheet that sets `display`. `.catbar` is `display:flex`,
so the attribute did nothing and the strip stayed on screen for good.

It was not only the strip. The same bug was quietly showing **the blocked bar on
every board** (`.blocked-bar` is flex), **the queue button when the queue was
empty**, **the delete button on a new channel**, and the extension-only rows in
settings — everything hidden with the attribute that also carries `.btn`, which
is `display:inline-flex`.

One rule at the top of the sheet, with the weight to win:
`[hidden]{display:none !important}`. The test is a fact about the file rather
than a computed style, since jsdom applies no CSS — but it is the fact that
matters, including that the rule comes before anything that sets `display`.

### The new-video dot — request 3

Three places it can sit — the card's **corner**, beside the **name**, or on the
**avatar** — plus its own size (4–14px) and its own colour, with an *accent*
button that hands it back to following the rest of the board. A colour input
cannot say "whatever the accent is" on its own, so that is a button beside it.

### The channel icon — request 4

A third shape (**rounded**, between circle and square) and an edge of its own:
**hairline**, **none**, or **accent**, the last taking the channel's category
colour with a soft ring outside it.

### Opens as a number — request 5

Not a restyled badge but a different thing to read, so it is drawn somewhere
else entirely: bottom-right of the card, in the display face at the name's own
size, tabular figures, digits only. The badge stands down while it is on, and
the badge row gets right-hand room so the two never collide. In the list layout
the number sits inline at the end of the row instead, since a list row has no
bottom-right corner to speak of.

### The name against the picture — request 6

`align-items: center` on the card's top row, which is now the default — a 17px
name sitting on the top edge of a 30px circle reads as a mistake. `top` is still
there as a choice for anyone who wants the old alignment.

### Text sizes — request 7

A **type** section: the wordmark (28–80), the channel name (12–26), the
description (9–17), and the badges (8–14). Each is a real px value the
stylesheet reads through a variable, so the board can be set to whatever is
comfortable rather than to whatever looked right on the machine it was written
on. The four presets set them too, so switching preset moves the type with
everything else.
