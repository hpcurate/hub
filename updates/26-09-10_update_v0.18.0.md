## What was done

The board has always answered the window — `auto-fill` plus `minmax` saw to
that, and the card itself has had a dial for nearly every part of it since 0.9.
The chrome around it answered nothing. Every size in the header, the control
bar, the chips and the sheets was a pixel that looked right on the machine it
was written on, which means the one thing this app could not do was get bigger.

### One dial over everything

**`--ui`** (settings → look → **text size**, 80–150%). Every type size and every
control height in the app is expressed as a multiple of it — the chrome in
`css/hub.css`, and the card's own four dials through the renderer, which now
writes `calc(17px * var(--ui))` where it used to write `17px`. So "make it
bigger" is one number rather than six, and the per-part dials stay exactly what
they were afterwards.

The control heights follow the type deliberately: a scaled label sitting in an
unscaled box is a button whose padding is wrong by the difference.

### And a second for the air

**`--dens`** (settings → look → **spacing**, 80–140%) multiplies padding and gap
and never a font size. The two are kept apart because "bigger text" and "more
room" are different complaints, and setting one to fix the other is how a layout
ends up wrong in both directions.

### The one type that had no dial at all

A card's `tag` and `seen` — the category name and the last-opened line — were
hardcoded at 10px, which is what the **badges** setting in settings → type was
quietly not reaching. They read `--badge-px` now, like every other badge.

### About the block that does the scaling

The scale block at the end of `css/hub.css` restates sizes that already exist
above it. That repetition is the mechanism, not an accident: nothing in it is a
new decision about how big anything should be — every number is the number that
was already in the rule it overrides, which is what makes the dial compute to
exactly the old sheet at 100%. It has to stay a repetition. Change a size in its
own rule and change it here too, or the default drifts away from the dial.

Both dials default to 1, so an install that never touches them is byte-for-byte
the board it was.
