# v0.16.0 — free placement and animation controls

- Manual mode places elements exactly, then saves each one as a fixed offset from its nearest responsive anchor.
- Each element can grow left, right, up or down from its saved point.
- The preview can hide or reveal disabled elements while editing.
- Animation controls are grouped together, with an independent speed for every animation family and additional effects.
- Background-image controls use clearer labels, five starting presets, and four more motion effects.
